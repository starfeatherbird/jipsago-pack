# 집사고싶나 콘텐츠 팩

집사고싶나 앱이 원격으로 내려받는 안내 정보(단계 로드맵·현장 체크리스트·대출 상품·지역 지원·용어·서류)입니다. 개인 정보는 없습니다.

- `pack/manifest.json`의 `packVersion`·`baseDate`가 기준. 파일 7개는 sha256으로 검증되며 전부 통과해야 앱이 교체합니다.
- 원본은 앱 저장소 `content/pack/`이고, `npm run pack:export`로 이 폴더에 복사한 뒤 push합니다. 여기서 직접 고치지 않습니다.
- 금리·한도 등 수치에는 기준일(`verifiedAt`)이 있고, 앱은 90일이 지나면 "확인 필요", 180일이 지나면 수치를 숨깁니다.
